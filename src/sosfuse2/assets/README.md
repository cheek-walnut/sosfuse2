Not bundled: the two IPRT inputs of the `usstd76` density asset, `tau_rayleigh_450nm_usstd.dat` and
`tau_absorption_320nm_usstd.dat` (phase E page of the IPRT intercomparisons), are downloaded from their original server on
first use and verified by SHA-256 (`iprt.py`, `generate_density_profile.py`; the terms of these files were not confirmed, so
they are not redistributed here).

The provenance fields inside the JSON assets (generator script paths, source file locations) refer to the sky-sos research tree.
