## Production paths this example does not run

Each pointer names the function or module where the path starts. Several are reached here too and return at once because the path is off (stratosphere, troposphere, spectral block, KSPLIT setting, one-worker pools).

- full grids and the grid rules (`jobs/run_state.py: refined_heights`, `jobs/run_state.py: refined_chi`): the reduced grid is fixed; the same grid without --reduced is refused with E_SETTINGS_GRID.
- CUDA transport (`backends/kernel.cu`, `solve/source_solver.py: Kernel.launch`): the NumPy backend is used.
- endpoint residency on the device (`solve/ray_geometry.py: TwoLayerGeometry.prepare`): the endpoint cache is built but the reduced solve reads its rays from TransientGeometry; nothing is uploaded.
- parallel preparation with more than one worker (`precompute/sun_parallel.py`, `precompute/column_parallel.py`, `precompute/ground_parallel.py`, `solve/ray_geometry_parallel.py`): every preparation pool is pinned to one worker and takes its serial path.
- KSPLIT split launches (`solve/ksplit.py`, `solve/source_solver.py: ksplit_setting`): CUDA only.
- stratospheric aerosol layer (`atmosphere/stratosphere.py: attach`): disabled in the example state.
- O4 absorption (`asset_tools/prepare_minor_absorbers.py`): O4 is off, so the run needs no prepared O4 asset (the empty work root has none).
- tropospheric Mie phase and two-layer aerosol (`atmosphere/tropo_mie.py: attach`, `atmosphere/tropo_profile.py: engine_hooks`): the example state has neither; aerosol scattering is Henyey-Greenstein with an exponential profile.
- spectral bands and wavelength chunks (`atmosphere/spectral.py: block`): one wavelength, 550 nm.
- signature, archive and verification (`jobs/run_state.py: signed_contract`, `outputs/pack_state.py: pack_state`, `jobs/run_state.py: verify_pack`): the table is saved as table.npz without a production signature, archive or verification.
- queue and persistent service (`jobs/pipeline.py`, `jobs/pipeline_execution.py`): one state in one process.
